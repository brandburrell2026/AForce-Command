Core principle:

Build architecture for everything. Expose features in phases.

IMPORTANT:

All analytics, event tracking, KPI dashboards, investor metrics, retention metrics, cohort reports, NPS reporting, and subscription analytics are INTERNAL ONLY.

These systems should NOT appear in the customer-facing app experience.

Users only see:

Hydration score
Ritual streaks
Progress
Reminders
Personal performance insights
Administrators only see:

NPS dashboards
Retention metrics
Cohort reports
Subscription analytics
Receipt funnel metrics
Investor reporting metrics
Activation funnels
KPI dashboards
Architecture:

Frontend App (User)

↓

Hidden Event Tracking Layer

↓

Analytics Database

↓

Restricted Admin Dashboard

Create this folder structure first:

/analytics

analytics_events.json

event_envelope.ts

event_dispatcher.ts

privacy_manager.ts

admin_dashboard.ts

Rules:

Build ONE event envelope for all events
Fields:

eventId
eventType
analytics_id
occurredAt
schemaVersion
payload

All events must be idempotent (fire once per eventId).

Build privacy layer BEFORE data collection
consent_granted required first
pseudonymized analytics_id
disable analytics until consent accepted
allow user delete-my-data requests
analytics hidden from users
Build role permissions
Roles:

user
admin
super_admin

No public analytics routes.

Launch Critical Events Only (Phase 1)
consent_granted

onboarding_completed

app_opened

session_started

ritual_started

ritual_completed

water_cycle_logged

water_goal_completed

hydration_score_updated

command_followed

impact_shown

orb_state_changed

receipt_scanned

receipt_verified

receipt_activated

survey_answered

notification_opened

subscription_started

Create analytics_events.json as source of truth
Each event should include:

event name
owner (mobile/backend/AI)
trigger
required payload fields
Do NOT build yet:
Advanced cohort reporting

Advanced attribution models

Investor reporting automation

Advanced referral systems

LTV:CAC dashboards

Advanced subscription analytics

Paywall optimization systems

Build architecture for these now, but do not expose or fully build them yet.
