Add full multi-language support and AI voice coaching localization to AForce OS.

IMPORTANT:
This is not basic translation.

This is a global, premium language system where:
- the UI adapts seamlessly to different languages
- AI coaching speaks naturally in the user’s language
- tone, clarity, and authority are preserved across all languages

The experience must feel:
- native to each language
- premium and consistent
- not robotic or poorly translated
- culturally aware where needed

==================================================
CORE GOAL
==================================================

Users must be able to:
- select their preferred language
- read all UI text in their language
- hear AI coaching in their language
- interact with voice commands in their language

The system must maintain:
- clarity
- authority
- simplicity
- premium tone

LANGUAGE SELECTION
==================================================

Add a Language Selector in:

Profile → Settings → Language

Options:
- language dropdown
- auto-detect option (based on device locale)

Persist user preference in database:
profiles.language

==================================================
UI TRANSLATION SYSTEM
==================================================

All UI text must be internationalized using a structured system.

Requirements:
- use i18n library (react-i18next or equivalent)
- store translations in JSON files
- no hardcoded strings

Structure:

/locales/en.json
/locales/es.json
/locales/fr.json
/locales/de.json
/locales/pt.json
/locales/it.json

Example:

{
  "log_water": "Log 1 Water Unit",
  "log_aforce": "Log 1 AForce Unit",
  "system_unstable": "System unstable. Act now."
}

==================================================
AI COMMAND LOCALIZATION
==================================================

AI coaching must generate responses in the user’s selected language.

Rules:
- always match UI language
- preserve tone (short, authoritative, precise)
- avoid literal translation errors
- avoid overly formal or robotic phrasing

Examples:

English:
“Take 1 AForce unit now. Recheck in 20 minutes.”

Spanish:
“Toma 1 unidad de AForce ahora. Revisa en 20 minutos.”

French:
“Prenez 1 unité d’AForce maintenant. Vérifiez dans 20 minutes.”

==================================================
VOICE OUTPUT (TEXT-TO-SPEECH)
==================================================

AI coaching must speak in the selected language.

Requirements:

Web:
- use Web Speech API with language-specific voices

Mobile:
- use Expo Speech with locale settings

Voice settings:
- correct language code (en-US, es-ES, fr-FR, etc.)
- natural voice if available
- fallback to system default if not

Voice must feel:
- calm
- authoritative
- clear
- not robotic
