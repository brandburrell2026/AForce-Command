Create the AForce Hydration Score Algorithm for the app.

Goal:
Build a 0–100 Hydration Score that powers the entire AForce OS experience.

This score should drive:
- Status Score color system
- AI Coach commands
- Risk state
- Voice alerts
- Pressure Mode
- Performance Loop footer
- Recheck timer

Core principle:
The score should feel like WHOOP Recovery meets Apple Fitness meets a hydration command system.

Inputs:
1. Thirst level: 1–5
2. Energy level: 1–5
3. Urine color: 1–8
4. Steps today
5. Weather temperature
6. Humidity
7. Workout status
8. Last hydration time
9. Sleep prep window
10. AForce product intake

Scoring:
Start with base score of 100.

Subtract points based on risk factors:

Thirst:
1 = subtract 0
2 = subtract 4
3 = subtract 9
4 = subtract 16
5 = subtract 24

Energy:
5 = subtract 0
4 = subtract 3
3 = subtract 8
2 = subtract 14
1 = subtract 20

Urine color:
1 = subtract 0
2 = subtract 2
3 = subtract 5
4 = subtract 10
5 = subtract 16
6 = subtract 22
7 = subtract 28
8 = subtract 35

Steps:
0–2,999 = subtract 0
3,000–6,999 = subtract 4
7,000–9,999 = subtract 8
10,000–14,999 = subtract 12
15,000+ = subtract 18

Temperature:
Below 70°F = subtract 0
70–79°F = subtract 3
80–89°F = subtract 7
90–99°F = subtract 12
100°F+ = subtract 18

Humidity:
Below 40% = subtract 0
40–59% = subtract 2
60–74% = subtract 5
75–89% = subtract 8
90%+ = subtract 12

Workout:
None = subtract 0
Light = subtract 5
Moderate = subtract 10
Hard = subtract 16
Extreme = subtract 22

Last hydration time:
0–60 minutes ago = subtract 0
61–120 minutes ago = subtract 5
121–180 minutes ago = subtract 10
181–240 minutes ago = subtract 16
240+ minutes ago = subtract 22

Sleep prep window:
If bedtime is within 2 hours and hydration score is below 75, subtract 5.
If bedtime is within 1 hour and hydration score is below 65, subtract 10.

AForce product intake:
If user consumed AForce within last 2 hours, add 8.
If user consumed AForce within last 4 hours, add 4.
If no AForce intake today, add 0.

Clamp final score between 0 and 100.

Status states:
85–100 = OPTIMAL
70–84 = STABLE
50–69 = DECLINING
30–49 = RISK
0–29 = CRITICAL

Color mapping:
OPTIMAL = neon green
STABLE = lime green
DECLINING = amber/yellow
RISK = orange
CRITICAL = red

Risk level:
85–100 = LOW
70–84 = WATCH
50–69 = MODERATE
30–49 = HIGH
0–29 = CRITICAL

Recheck timer:
OPTIMAL = 60 minutes
STABLE = 45 minutes
DECLINING = 30 minutes
RISK = 16 minutes
CRITICAL = 4 minutes

Pressure Mode:
Activate Pressure Mode if:
- score is below 50
- risk level is HIGH or CRITICAL
- user ignores command for more than 50% of recheck timer
- score drops by 15+ points since last check

Commands:
Generate dynamic AI Coach commands based on score and inputs.

Examples:

OPTIMAL:
“Hold the line. Maintain hydration rhythm.”

STABLE:
“Drink 12 oz of water within the next 45 minutes.”

DECLINING:
“Drink 16 oz of water and take 1 AForce stick now.”

RISK:
“Drink 20 oz of water with electrolytes now. Recovery window is open.”

CRITICAL:
“Immediate hydration required. Drink 20 oz now and begin recovery protocol.”

Sleep prep command:
If bedtime is within 2 hours:
“Drink 20 oz of water and take 1 AForce RTD before sleep.”

Heat command:
If temperature is above 85°F:
“Heat exposure detected. Increase fluid intake now.”

Workout command:
If workout is moderate or higher:
“Training load detected. Replace fluids and electrolytes now.”

Output object:
The algorithm should return:

{
  score: number,
  status: string,
  riskLevel: string,
  colorToken: string,
  recheckMinutes: number,
  pressureMode: boolean,
  command: string,
  reason: string,
  confidence: number,
  signals: string[],
  recommendedFluidOz: number,
  recommendedAForceProduct: string,
  nextEvaluationTime: string
}

Confidence logic:
Start at 70%.
Add:
+10 if urine color is provided
+8 if thirst is provided
+8 if weather is available
+6 if steps are available
+6 if last hydration time is available
Cap at 98%.

Signals:
Return 3–5 readable signals explaining the score.
Examples:
- “Hydration trend declining”
- “Urine color elevated”
- “Activity load elevated”
- “Heat exposure detected”
- “Sleep prep window open”
- “AForce intake confirmed”

Build clean reusable code.

Create:
- hydrationScore.ts
- getHydrationScore(inputs)
- getStatusFromScore(score)
- getStatusColor(score)
- getRiskLevel(score)
- getRecheckMinutes(score)
- shouldActivatePressureMode(score, previousScore, ignoredCommand, elapsedTimerPercent)
- generateHydrationCommand(score, inputs)
