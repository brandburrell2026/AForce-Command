==================================================
1. HYDRATION SCAN SYSTEM
==================================================

Build a feature called:

Hydration Scan

Purpose:
Allow users to scan barcodes, QR codes, and AForce product packaging in real time to instantly log hydration products, compare products, and update their performance protocol.

This must feel premium, fast, and intelligent.

CORE CONCEPT:
User scans a product.
AForce OS instantly identifies it.
The system then:
- recognizes the product
- logs intake if desired
- compares it to AForce products
- tells the user whether it fits their current state
- updates score / protocol if consumed

SUPPORTED SCAN TYPES:
- barcode scan
- QR code scan
- AForce product scan
- competitor product scan
- future NFC-ready architecture placeholder

MAIN USER FLOWS:

FLOW 1: Scan to Compare
- user opens Hydration Scan
- scans competitor product or AForce product
- app identifies product
- app shows:
  - product name
  - hydration profile
  - electrolyte profile
  - sugar level
  - fit score for current user state
  - AForce equivalent or better recommendation
- show “Best Option Right Now”

FLOW 2: Scan to Log Intake
- user scans product
- app asks:
  - “Log this product?”
- if yes:
  - create intake event
  - update hydration score
  - update state
  - update protocol
  - update pulse
  - possibly trigger AI command

FLOW 3: Scan to Recommend AForce Alternative
- user scans Gatorade, Liquid IV, Pedialyte, LMNT, or any competitor
- app compares against user’s current need
- app shows:
  - “How this compares to AForce”
  - “Best AForce replacement”
  - “Take 1 AForce Stick now” or similar action

HYDRATION SCAN SCREEN REQUIREMENTS:
Create a screen called:
Hydration Scan

Sections:
1. Camera scan area
2. Scan result card
3. Product details card
4. Fit score card
5. AForce comparison card
6. Log intake CTA
7. View full comparison CTA

SCAN OUTPUT MODEL:
For each scanned product return:
- product_id
- product_name
- brand
- category
- hydration_speed
- electrolyte_density
- sugar_level
- stimulant_level
- recovery_fit
- performance_fit
- current_fit_score
- aforce_equivalent
- recommendation

  "brand": "Gatorade",
  "category": "sports_drink",
  "hydration_speed": 70,
