Add a new feature called “Social Mode” to AForce OS.

IMPORTANT:
This is not a drink tracker.
This is a real-time alcohol mitigation and hydration control system.

The goal:
Help users drink socially WITHOUT losing control of their hydration, performance, and next-day recovery.

This feature should feel:
- intelligent
- protective
- non-judgmental
- high-end
- like a personal performance coach during drinking

==================================================
CORE FUNCTION
==================================================

When Social Mode is ON:
- alcohol intake is tracked
- hydration decay increases dynamically
- AI commands become more frequent and precise
- system actively prevents dehydration
- hangover risk is calculated in real time

==================================================
USER FLOW
==================================================

1. User taps:
“Activate Social Mode”

2. System asks:
“What are you drinking?”

Options:
- Beer
- Wine
- Cocktail
- Liquor (straight)
- Custom

3. User selects drink type + quantity

4. System begins real-time tracking and guidance

==================================================
ALCOHOL IMPACT MODEL
==================================================

Each drink type has a hydration impact multiplier:

Beer:
- mild impact
- decay +10–15%

Wine:
- moderate impact
- decay +15–20%

Cocktail:
- high impact (sugar + alcohol)
- decay +20–30%

Liquor:
- strongest impact
- decay +25–35%

Formula:
AlcoholImpact = BaseDecay × AlcoholMultiplier

==================================================
REAL-TIME COMMAND ENGINE
==================================================

After each drink, system must respond with:

- hydration command
- timing instruction
- next action

Examples:

“Drink 1 water unit now.”
“Take 1 AForce RTD now.”
“Alternate water before next drink.”
“Slow intake. Hydration dropping.”

==================================================
HYDRATION PROTOCOL RULES
==================================================

Golden Rule:
👉 1 alcohol drink = required hydration response

System enforces:
- water between drinks OR
- AForce RTD for recovery boost

Example flow:

Drink logged →
System:
“Take 1 water unit now. Recheck in 15 minutes.”

Next drink →
System:
“Take 1 AForce RTD now to stabilize.”

==================================================
HANGOVER RISK ENGINE
==================================================

Create a Hangover Risk Score:

Factors:
- number of drinks
- hydration compliance
- time between drinks
- body weight
- environment (heat increases risk)

Output:
- LOW
- MODERATE
- HIGH
- CRITICAL

Display:

“Hangover Risk: Moderate”
“Hydrate now to reduce impact”

==================================================
PREDICTIVE WARNING SYSTEM
==================================================

System should warn BEFORE damage happens:

“You are 20 minutes from dehydration drop.”
“Next drink without hydration will push you into DEPLETED.”
“Recovery window closing.”

==================================================
VISUAL SYSTEM
==================================================

Keep current UI.

Add Social Mode layer:

- subtle purple / amber accent
- glow shift during alcohol intake
- orb pulse becomes slightly unstable if hydration drops

State overlay:
“SOCIAL MODE ACTIVE”

==================================================
AI COACHING TONE
==================================================

Tone must be:
- calm
- controlled
- not judgmental
- not preachy

Never say:
“Don’t drink”

Instead:
“Stay in control.”
“Hydrate now.”
“Balance intake.”

==================================================
VOICE COACHING
==================================================

Examples:

“You’re dropping. Drink water now.”
“Take AForce now to stabilize.”
“You’re in control. Maintain hydration.”

Keep short and direct.

==================================================
CONFIRMATION LOOP
==================================================

After hydration command:

Ask:
“Did you hydrate?”

If YES:
- reduce hangover risk
- reward +2 or +3

If NO:
- increase decay
- increase hangover risk

==================================================
RECOVERY MODE (POST DRINKING)
==================================================

When user stops drinking:

System switches to:
“Recovery Mode”

Commands:
“Take 1 AForce now.”
“Drink 2 water units before sleep.”
“Stabilize overnight.”

Morning:
“You avoided major dehydration. Good control.”

Simulate:
- increased heart rate
- rising body temp
- dehydration signals

Map:
- alcohol increases stress signals
- hydration reduces them
