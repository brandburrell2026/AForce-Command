11. Dynamic State System (Critical)

The UI may adapt based on readiness, recovery, hydration, or journey state — but transitions must remain emotionally premium and calm.

DO NOT create:
- emergency aesthetics
- panic states
- aggressive warning screens
- tactical red alert systems
- medical urgency visuals

The system should feel:
- ambient
- intelligent
- adaptive
- elegant
- emotionally stable

Dynamic states should subtly shift:
- color temperature
- glow intensity
- motion speed
- messaging tone
- animation softness

WITHOUT making the user feel:
- unsafe
- failing
- unhealthy
- monitored
- judged

Color System Rules

HIGH READINESS / LOCKED IN
Palette:
- emerald
- aqua
- platinum
- soft cyan glow

Emotion:
- flow
- confidence
- momentum
- clarity

MID STATE / BALANCED
Palette:
- teal
- ocean blue
- muted silver

Emotion:
- stable
- calm
- centered

RECOVERING
Palette:
- soft amber
- warm teal
- muted gold accents

Emotion:
- restoration
- reset
- support

RESET NEEDED
Palette:
- darker neutrals
- low-energy teal
- soft dimmed amber

Emotion:
- slower pace
- recovery active
- gentle reset

Avoid:
- bright red
- flashing alerts
- hazard colors
- emergency gradients
- warning animations

Red may ONLY appear as:
- tiny accent indicators
- minimal edge highlights
- subtle micro-signals

Never as the dominant screen emotion.

Animation Rules

Higher readiness:
- smoother motion
- brighter glow
- slightly faster ambient animation

Lower readiness:
- softer movement
- slower pulse
- dimmer environment
- calmer transitions

Never use:
- shaking
- flashing
- rapid pulsing
- alarm behavior

Messaging Must Also Adapt

HIGH READINESS:
“Flow state active.”
“Ready for your next experience.”

BALANCED:
“Recovery stable.”
“Hydration maintained.”

RECOVERING:
“Recovery window open.”
“Water cycle recommended.”

RESET NEEDED:
“Recovery active.”
“Take a slower recovery moment.”

Avoid:
- “critical”
- “urgent”
- “unstable”
- “failure”
- “depleted”
- “warning”

The system should always feel:
supportive > corrective
ambient > aggressive
luxury > tactical
wellness > diagnostics

This is a premium adaptive wellness environment — not a monitoring dashboard.
