Refine the AForce Protocol screen to elevate the experience from a high quality startup app into a world class premium performance operating system.

The current direction is strong. This update should focus on polish, emotional intelligence, visual restraint, and long term habit forming UX.

1. Remove direct product selling language
Replace all commands mentioning:
- “Take 1 AForce stick”
- “Take 2 sticks”

with more premium hydration and recovery guidance.

Examples:
- “Increase electrolyte intake.”
- “Drink 16 ounces now.”
- “Recovery protocol activated.”
- “Hydration correction recommended.”

The app should feel coach driven, not sales driven.

2. Refine warning and depletion colors
The current orange/red tones feel slightly too aggressive and gamer-like.

Adjust them to feel:
- deeper amber
- muted performance orange
- luxury warning tones
- softer premium reds

Avoid esports or cyberpunk color intensity.

3. Upgrade command history intelligence
Enhance the Command History section to feel more AI driven and performance aware.

Add future ready structure for:
- recovery trend indicators
- hydration stability
- projected performance recovery
- score movement direction
- recovery momentum

The UI should feel like a living intelligence system, not static logs.

4. Improve bottom navigation polish
Refine the bottom nav bar with:
- thinner icon weights
- slightly more spacing
- more elegant active state behavior
- softer transitions
- cleaner typography

The nav should match the premium quality of the rest of the interface.

5. Refine language system wide
Shift wording away from clinical/compliance terminology.

Examples:
- “Weekly Compliance” → “Recovery Consistency”
- “Completed” → “Recovery Progress”
- “Target” → “Hydration Goal”

The app should feel:
- intelligent
- elite
- motivating
- emotionally calm
- performance focused

6. Add more emotional intelligence to the protocol system
Protocols should feel adaptive and human.

Examples:
- “Recovery trending upward.”
- “Hydration stabilizing.”
- “Performance state improving.”
- “Maintain rhythm.”
- “Stay consistent.”

Avoid overly robotic or harsh commands.

7. Increase premium feel through subtle polish
Focus on:
- smoother animations
- softer card transitions
- refined hover/glow behavior
- improved spacing rhythm
- subtle depth layering
- cleaner card elevation

The UI should feel:
- luxury athletic technology
- AI recovery system
- elite wearable ecosystem

NOT:
- gamer HUD
- esports dashboard
- cyberpunk interface

8. Overall direction
The product should feel like:
“the operating system for human performance and recovery.”

Think:
- WHOOP
- Oura
- Apple Fitness
- Levels
- Formula 1 telemetry
- luxury performance technology

Do not redesign the app architecture.
This is a high end refinement and emotional UX polish pass.
