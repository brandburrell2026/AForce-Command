Main features to build:

1. Voice Command Engine
Create a reusable voice service that can speak any AForce command using ElevenLabs.

2. Hydration Score Voice Alerts
When the user’s hydration score changes, trigger different voice alerts:

Score 85–100:
“System optimized. Hydration status is elite.”

Score 70–84:
“Performance stable. Maintain hydration rhythm.”

Score 50–69:
“Hydration score declining. Correct now.”

Score 30–49:
“Risk increasing. Drink 12 ounces with AForce now.”

Score below 30:
“Critical hydration risk. Execute recovery command immediately.”

3. Risk Timer Voice Alerts
Add voice alerts when the risk timer enters:

16 minutes:
“Early risk detected. Hydration correction recommended.”

8 minutes:
“Performance risk rising. Take action now.”

4 minutes:
“High risk state. Immediate hydration required.”

0 minutes:
“Hydration command failed. Recovery protocol activated.”

4. System Command Voice
When AForce gives the user a command, the app should say it out loud.

Examples:
“Drink 12 ounces of water with one AForce stick now.”
“Complete your hydration cycle.”
“Electrolytes required based on current conditions.”
“Heat exposure detected. Increase fluid intake.”

5. Completion Reward Voice
When the user taps Complete Cycle, trigger:

“Hydration cycle complete. System reset.”
“Command executed. Performance restored.”
“Recovery confirmed. You are back in range.”

6. Pressure Mode
Create a mode where the voice becomes more urgent when risk is high.

Normal Mode:
Calm and precise.

Pressure Mode:
Shorter, sharper, more direct.

Example:
Normal:
“Hydration score declining. Correct now.”

Pressure:
“Risk rising. Drink now.”

7. User Voice Settings
Add a settings panel where the user can:
Turn voice on/off
Choose voice intensity: Calm, Standard, Pressure
Choose when voice plays: Always, Only Risk Alerts, Only Commands, Muted
Replay last command
