Add a Social Sharing system to AForce OS that allows users to share performance results, achievements, and status moments across social platforms.

IMPORTANT:
This is NOT social media inside the app.
This is NOT a feed or timeline.

This is a controlled, premium sharing system that turns AForce results into:
- status signals
- performance proof
- shareable moments
- viral growth loops

The system must feel:
- clean
- powerful
- minimal
- premium
- Apple/Nike level design
- not spammy
- not cluttered

==================================================
CORE CONCEPT
==================================================

Users don’t “post.”

Users share:
→ proof of performance
→ system-driven results
→ real metrics

Every share must feel like:
“I’m operating at a higher level.”

==================================================
WHAT USERS CAN SHARE
==================================================

Create shareable moments for:

1. Performance Score
Example:
“Score: 88 — Balanced”

2. Status Pulse State
Peak / Balanced / Recovering / Depleted

3. Protocol Completion
“Recovery cycle completed”

4. Performance Gain
“+12 improvement today”

5. Streaks
“7 day consistency streak”

6. Competition Rank
“Top 5 in Miami”
“#1 in my team”

7. Heat Guard Save Moment
“Heat risk detected and corrected”

8. AI Command Completion
“System executed”

9. Morning Reset
“Daily system reset complete”

10. Product Use (optional)
“Executed with AForce”

==================================================
SHARE TYPES
==================================================

Create 3 share formats:

1. CARD SHARE (default)
- clean square format
- optimized for Instagram
- includes:
  - score
  - state
  - short message
  - AForce branding (subtle)

2. STORY SHARE
- vertical format
- minimal text
- bold visuals
- animated background (optional)

3. TEXT SHARE
- copy-only version for X / Threads
- clean performance statement

==================================================
SHARE CARD DESIGN
==================================================

Design rules:

- dark background
- premium typography
- minimal layout
- large score number
- small supporting text
- subtle AForce logo (no heavy branding)

Examples:

“Score: 88  
Balanced  
System in control”

OR

“+12 Today  
Recovery Complete  
Back in control”

==================================================
VOICE / COPY RULES
==================================================

Use AForce tone:

- direct
- confident
- minimal
- no hype
- no emojis
- no slang
- no hashtags by default

DO NOT use:
- “feeling great”
- “crushing it”
- “awesome”
- “let’s go”

USE:
- “Balanced at 88”
- “Recovery complete”
- “Back in control”
- “System executed”

==================================================
SHARE FLOW
==================================================

1. User taps “Share” from:
   - Home screen
   - Completion state
   - Competition screen
   - Achievement modal

2. Show Share Preview screen

3. User selects:
   - format (card / story / text)
   - message variation (3 options max)

4. User taps “Share”

5. Open native share sheet

==================================================
SHARE PREVIEW SCREEN
==================================================

Include:

- preview image/card
- toggle between formats
- edit message (optional but limited)
- platform icons (IG, X, iMessage, etc.)
- CTA: “Share”

==================================================
AUTOMATIC SHARE MOMENTS (OPTIONAL)
==================================================

Suggest sharing after:

- major score increase
- streak milestone
- top leaderboard rank
- protocol completion
- recovery from depleted state

Use a prompt like:

“Share your result?”

Keep it subtle.
Do NOT interrupt the flow aggressively.

==================================================
VIRAL LOOP DESIGN
==================================================

Every shared post should include:

- subtle AForce branding
- optional:
  “Powered by AForce”

Do NOT force:
- referral links
- discount spam
- aggressive marketing

Goal:
curiosity → click → download
