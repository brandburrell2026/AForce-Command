CRUISE MODE

Internal Build Only.

Purpose
Help guests enjoy more, recover smarter, and stay ready for the next experience.
Not alcohol tracking. Not medical monitoring. Not hospitality CRM.

Feature Flags
Internal: cruiseModeEnabled = true
Public: cruiseModeEnabled = false
journeyPulseEnabled = false
commerceEnabled = false
inventoryEnabled = false
stateroomDeliveryEnabled = false
prePortEnabled = false
excursionReadinessEnabled = false

Six Blocks:

Block 1 — Guest Readiness Signal
States: LOCKED IN, BALANCED, RECOVERING, RESET NEEDED
Subtitle: Ready for your next experience.
Inputs: Recovery Capacity, Heat, Humidity, Activity, Water Cycles
Output: One state only.

Block 2 — Today's Flow
Shows journey rhythm only.
Example: Pool — Recovery Window — Explore — Dinner
Button: ADJUST MY DAY

Block 3 — Port Signal
Shows: Port name, Heat, Humidity, Journey Intensity
Journey Intensity states: LOW, MODERATE, ELEVATED
Never implies route advice, safety advice, or activity prescription.
Example: COZUMEL — Journey Intensity: MODERATE — Recovery Window: OPEN

Block 4 — Recovery Window
States: Pool Recovery, Dinner Recovery, Port Recovery, Night Recovery
Message: Recovery available.
Commerce OFF — water only.
Commerce ON — water first then optional AForce product. Never force product.

Block 5 — Cabin Reset
Trigger: Return to cabin.
Message: WELCOME BACK — Signal: RECOVERING
Recommended: Complete 1 Water Cycle
Button: START RESET

Block 6 — Journey Pulse
Generated from: itinerary, weather, time of day, onboard rhythm, environment.
No guest data. No aggregation.
Examples: Western Caribbean — PEAK DAY. Sea Day — BALANCED.

Block 7 — Pre-Port Recovery Intelligence
Trigger: Evening before port day. 8pm to 10pm.
Command: Water first. 12 to 16oz.
Example: "Tomorrow is Cozumel. High heat expected. Complete your recovery cycle tonight to maximize your day."
Feature flag: prePortEnabled = false until Phase 2.

Block 8 — Morning Excursion Readiness
Trigger: Morning of port day. 6am to 9am.
Signal: READY or RESET FIRST
Example ready: "System stable. Good morning for activity."
Example reset: "Recovery still active. Hydrate before your excursion."
Compliance: Wellness guidance only. Never implies medical clearance.
Feature flag: excursionReadinessEnabled = false until Phase 2.

Hidden Engine
Inputs: Journey Type, Heat, Humidity, Time, Port, Activity, Water Cycles, Recovery Capacity, Sleep optional, HydroScan optional.
No alcohol-specific UI, scoring, or user-facing alcohol outputs.
Outputs: Readiness, Recovery Window, Journey Flow, Cabin Reset, Recovery Demand, Pre-Port Command, Morning Signal.

Commerce Layer
Feature flag only. Off by default.
Replace BUY NOW with DELIVER TO STATEROOM or ADD TO JOURNEY.
Water always first. Never force product.

Compliance
Never show: safe to drink, safe to drive, BAC, alcohol score, medical advice.
Only show: recovery, readiness, hydration guidance, performance guidance.
Disclaimer: "Cruise Mode provides estimated recovery and hydration guidance only and is not a medical, diagnostic, safety, or navigation tool."

Release Plan
Internal now — cruiseModeEnabled only.
Phase 1 public — Journey, Signal, Flow, Port Signal.
Phase 2 — Recovery Windows, Pre-Port, Morning Readiness.
Phase 3 — Commerce.
Phase 4 — Enterprise.
