Add a live GPS-based competition map to AForce OS inspired by the energy of Strava, but redesigned for hydration, performance, and territory-based competition.

IMPORTANT:
Do not build a running route map.
Do not make this a workout tracker.
Do not copy Strava directly.

This feature must feel like:
- live competition
- city pride
- territory control
- performance culture
- premium sports intelligence

FEATURE NAME:
AForce Territory

CORE CONCEPT:
AForce Territory is a live competition map where cities, states, teams, and communities compete based on hydration performance, compliance, and recovery momentum.

The map should visualize who is winning, where momentum is building, and which locations are dominating performance.

==================================================
PRIMARY COMPETITION MODES
==================================================

Build map support for:

1. City vs City
2. State vs State
3. Team vs Team
4. Friends / Circle map
5. Event-based competitions

==================================================
MAP PRINCIPLES
==================================================

The map is NOT for exact user tracking.
The map is for aggregated competitive visualization.

Do not show exact personal GPS points publicly.

Use:
- city-level aggregation
- metro-level clusters
- anonymized density
- team territory zones
- heat overlays
- region color states

==================================================
WHAT THE MAP SHOULD SHOW
==================================================

For each city / state / team area, show:

- average hydration score
- average competition score
- protocol completion rate
- active user count
- streak density
- trend direction
- momentum change
- current rank
- battle status

==================================================
MAP VISUAL MODES
==================================================

Create 4 map layers:

1. Territory Mode
Shows regions color coded by winning performance level

2. Heat Mode
Shows where activity / compliance is strongest

3. Momentum Mode
Shows which cities or states are rising or falling fastest

4. Battle Mode
Shows direct active rivalries like Miami vs New York

==================================================
COMPETITION SCORING
==================================================

Map ranking should be based on competition score, not raw volume only.

Suggested formula:

territory_score = (
  avg_performance_score * 0.35 +
  protocol_completion_rate * 0.25 +
  streak_density * 0.15 +
  recovery_efficiency * 0.15 +
  momentum_score * 0.10
)

Use mock calculations for now.

==================================================
CITY / STATE CARD UI
==================================================

When user taps a city or state on the map, show a detail card with:

- city or state name
- current rank
- average score
- participants
- trend arrow
- streak density
- battle status
- “Challenge this city” CTA
- “Join competition” CTA

Example:
Miami
Rank #2
Average Score: 86
Participants: 4,234
Trend: Up
Battle: Miami vs New York active
