Add Phantom Band voice trigger and hardware integration to AForce OS.

IMPORTANT:
This is not a smartwatch clone.
This is not a general-purpose wearable.

Phantom Band is a lightweight performance companion device that acts as a trigger surface and signal relay for AForce OS.

The Phantom Band should feel:
- invisible
- premium
- fast
- intelligent
- athletic
- like hardware built for performance, not distraction

==================================================
CORE CONCEPT
==================================================

Phantom Band is a low-friction wearable that lets the user trigger AForce OS voice interactions and receive silent performance signals without opening the app.

The hardware should support:
- voice trigger initiation
- tactile interaction
- passive signal feedback
- Bluetooth sync with AForce OS
- private user-only feedback

It must NOT feel like:
- a smartwatch
- a chat device
- a noisy consumer gadget

==================================================
PRIMARY HARDWARE USE CASES
==================================================

1. Voice Trigger
User taps or presses Phantom Band to activate voice mode in AForce OS.

2. Silent Signal Feedback
Band gives light / haptic feedback when:
- score drops
- recovery is needed
- protocol window opens
- heat risk rises
- user enters depleted state

3. Quick Command Acknowledgement
User can confirm a command from the band with:
- single tap
- double tap
- press and hold

4. Passive Sync
Band syncs performance state from app and mirrors state visually

==================================================
PHANTOM BAND INTERACTION MODEL
==================================================

Supported gestures:
- single tap
- double tap
- long press
- press and hold

Gesture mapping:
- single tap = wake band / acknowledge signal
- double tap = trigger voice input
- long press = quick status check
- press and hold = emergency voice trigger

==================================================
VOICE TRIGGER FLOW
==================================================

Flow:
1. User double taps Phantom Band
2. Band sends BLE trigger to phone
3. AForce OS opens voice command mode instantly
4. App begins listening
5. User speaks
6. Intent is classified
7. Action is executed
8. AI returns command
9. Band confirms completion via haptic + LED pulse

Example:
Double tap band
→ phone listens
→ user says “What should I do?”
→ AForce responds
→ band glows amber and vibrates once if recovery needed

==================================================
HARDWARE FEEDBACK SYSTEM
==================================================

The Phantom Band should support:
- LED color states
- pulse patterns
- haptic patterns

LED / state mapping:
- PEAK = white/silver steady glow
- BALANCED = teal steady glow
- RECOVERING = amber slow pulse
- DEPLETED = red fast pulse

Haptic feedback examples:
- protocol window open = 1 short pulse
- recovery needed = 2 medium pulses
- depleted = 3 sharp pulses
- command confirmed = 1 clean tap
- critical heat risk = urgent pulse pattern
