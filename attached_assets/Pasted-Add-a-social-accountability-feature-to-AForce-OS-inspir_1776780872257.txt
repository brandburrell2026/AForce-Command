Add a social accountability feature to AForce OS inspired by Apple Watch activity sharing, but redesigned for hydration and performance.

IMPORTANT:
Do not copy Apple’s style directly.
Do not make this a generic social feed.
Do not make it feel casual or gimmicky.

This feature must feel:
- premium
- performance-driven
- selective
- accountability-focused
- motivating
- clean

FEATURE NAME:
AForce Circles

CORE CONCEPT:
Users can share their hydration and performance progress with selected friends, teammates, family members, coaches, or accountability partners.

The purpose is:
- accountability
- motivation
- competition
- support
- consistency

This is not general social media.
This is a private performance network.

==================================================
WHAT USERS CAN SHARE
==================================================

Each user can choose to share:

- hydration score
- current state (Peak, Balanced, Recovering, Depleted)
- trend direction
- daily protocol completion
- streak
- competition standing
- recovery status
- performance gains

==================================================
PRIVACY LEVELS
==================================================

Allow users to choose visibility settings:

1. Private
2. Circle Only
3. Team / Coach
4. Public Share Card Only

Also allow field-level controls:
- share score only
- share state only
- share streak only
- share full progress

==================================================
CIRCLE SYSTEM
==================================================

Users can:
- invite friends
- accept circle requests
- remove friends
- mute people
- organize circles (friends, team, coach, family)

Each circle member can see:
- current hydration score
- state
- streak
- whether protocol is complete
- if the user is trending up or down

==================================================
REACTIONS / COMMENTS
==================================================

Do NOT use generic social comments by default.
Use performance-first reactions.

Built-in reactions:
- Stay on cadence
- Strong recovery
- Back in control
- Catch up now
- You’re trending down
- Finish the cycle
- Elite today
- Hold the line

Optional:
Allow short custom comments, but keep them constrained and clean.

==================================================
SOCIAL UI
==================================================

Create a tab or section called:
AForce Circles

Include:

1. My Circle feed
- shows friends’ current performance cards

2. Friend Detail view
- score
- state
- streak
- protocol completion
- send reaction

3. My Shared Status
- preview what others see about me

4. Invite / Manage Circle
- add / remove / organize people

==================================================
CARD DESIGN
==================================================

Each friend card should show:
- name
- avatar placeholder
- score
- state
- trend arrow
- streak
- protocol status
- reaction button

Style:
- dark premium UI
- performance-first
- subtle motion
- no clutter
- no social media aesthetics

==================================================
NOTIFICATIONS
==================================================

Users can receive:
- friend completed protocol
- friend hit a streak milestone
- friend reacted to your status
- friend challenged you
- friend is trending down and needs support

Keep notifications minimal and useful.

==================================================
SOCIAL ACCOUNTABILITY FEATURES
==================================================

Add:
- direct challenge system
- “match my score” challenge
- “complete your cycle” reminder
- weekly consistency challenge
- circle ranking

==================================================
WOW MOMENTS
==================================================

1. Friend sends “Back in control” after recovery
2. Circle sees user hit Peak
3. User moves above a friend in circle leaderboard
4. Two friends complete protocol within minutes and both get shared celebration state
