Do not attach a face photo, preview screenshot, raw frame, URI, base64,
thumbnail, precise location, participant identifier, device identifier, or
individual appearance/health observation. A screenshot of a non-image result
screen may still expose account or device details; record the QA code in text
instead. Physical-device cleanup, sandbox, network, log, cache, crash, and
backup claims require separately documented inspection, not an inference from
the UI. Publish only privacy-reviewed aggregates with adequate denominators
in a validation evidence packet.
