# HydroScan film flow: the uncut phone recording

The first milestone is one uncut screen recording on a real iPhone, matching the film's
2:17 to 2:42. Nothing below has been run. Fill in the build number and each result.

**Build:** ______  **Phone:** ______  **Date:** ______

## Before recording

1. Install the build from TestFlight.
2. Profile → Developer → turn on the label reader.
3. Have ready: one AFORCE can, one labelled 500 mL (16.9 fl oz) water bottle, about half full.
4. Start an iPhone screen recording. Do not stop it until step 12.

## The take

| # | Do this | The film shows | Result |
|---|---|---|---|
| 1 | Open Scan | HYDROSCAN, status strip, brackets with ticks, Drink / Barcode / Type it, N–И button | Not run |
| 2 | Point at the front of the AFORCE can | Searching → Reading | Not run |
| 3 | Hold steady | Brackets settle around the can; size appears beside the frame | Not run |

| 10 | Drag the line down the bottle, then tap ½ | Fill, slider and number move together; 8.5 fl oz for a 16.9 fl oz bottle | Not run |
| 11 | Tap Review, then Log 8.5 fl oz | Review, then Logged with Undo | Not run |
| 12 | Tap Undo, then stop recording | Removed; nothing left logged | Not run |

## What to note for each lock

- Seconds from pointing to Locked.
- Whether the brackets sat on the drink, on the label only, or stayed in the middle.
- Whether Light, Steady and In frame lit up, and whether they were right.
- For the AFORCE can: the name shown, and whether "AFORCE PACKAGING · NOT VERIFIED YET" appeared.

## Still needed for a real AFORCE match

From the can that is filmed: the barcode digits, the net contents as printed, and the
exact front-label wording. Until then an AFORCE match is unverified and says so.
