# Product Experience Specification

**Status:** Canonical (tier 4) · **Updated:** 2026-07-22

Surfaces, navigation, and the command experience. Consolidates the surface material previously
scattered across four tier-5 documents.

---

## 1. The experience contract

> Open app. Get command. Execute. Close app. Live life. Come back only when needed.

Constitution Principle 11. Every surface decision serves this. AForce OS is measured by the
reduction of required interaction over time, not by engagement volume.

**Mantra:** Pause → Hydrate → Lock In → Perform.

## 2. Navigation — locked

**5 visible tabs. No new tabs. No navigation redesign.** (Build Rule 14, Founder Decision 1.)

| Tab | Purpose |
|---|---|
| **Home** | The single command surface |
| **Hydration** (Journal) | Logging and history |
| **Protocols** | Structured routines |
| **Community** | Circles, competition |
| **Profile** | Identity, settings, subscription |

Additional surfaces exist as stacked or hidden routes — engines built, surfaces revealed over
time (`href:null` for hidden tabs). Hidden or staged routes include HydroScan, social variants,
sleep, cruise, circles, Guardian/heat, ring session, subscription management, legal, clutch,
phantom, territory, urine-check, onboarding, and weekly report.

**"Build 100% · Show 10% · Unlock over time. One Engine. Multiple Experiences."**

## 3. Home composition

Readiness eyebrow → status headline → Status Pulse Orb → status label → live status line →
consequence line → status-based primary CTA → quick-action grid → Hydration Status card →
flag-gated zones (render nothing when off) → pinned AFORCE brand footer.

**Score Protection on Home:** every Home surface is a **read-only projection of already-completed
behavior**. Nothing on Home awards or inflates score.

## 4. Cold-launch opening sequence

Two stacked overlays driven by the AppShell phase machine (`opening → welcome → done`), mounted
as overlays so they touch **no routing** — no redirect-loop risk.

1. **Cinematic** (4 stages): water-drop symbol → AFORCE wordmark + brand-red hairline +
   "Performance Is Non-Negotiable" → PAUSE/HYDRATE/LOCK IN/PERFORM ritual stagger →
   "TODAY'S READINESS" + count-up to the live score with a **band-aware** caption.
2. **WelcomeHero** photo front door → GET STARTED routes to onboarding, SIGN IN to auth.

**Band-aware is a trust rule:** a DEPLETED user reads "REHYDRATE NOW", never "READY TO PERFORM".

Motion is slow and crossfading, tap-anywhere-to-skip, fully reduced-motion aware. Display-only
projection of score — never awards or fabricates.

## 5. Today's Command

The core output. Water-First ordering is absolute:

> **Water → Command → Optional support → Score Update**

Default recommendation copy begins with `HYDRATE NOW` / `Start with water`. Optional hydration
support may be suggested **only after** hydration needs are evaluated. Products never precede
water. When no product is needed, the OS says so.

## 6. Command Confidence display (§58)

UI surfacing on the existing Signal Weighting Engine and Command Confidence. **No new calculation
logic.** Applies to Today's Command, HydroScan Performance Fit, Recovery Window, and Sun Recovery
Mode.

## 7. Where new intelligence surfaces (and does not)

Founder Decision 1: new systems must not create public navigation tabs and must not be exposed
merely because their backend exists.

| System | Surface plan |
|---|---|
| §38 Performance Knowledge Graph™ | **None.** Headless substrate. Never shown as a graph. |
| §39 Prediction Engine™ | Phase 2 earliest, inside existing surfaces, **§42 gate first** |
| §40 Performance DNA™ | Phase 2+, inside existing surfaces, **§42 gate first** |
| §61 Your Body's Manual | Phase 2, within an existing surface |
| §61 Confidence Journey | Phase 2, within an existing surface |

Every one lands inside an existing surface or stays headless.

## 8. Accessibility and localization

- Reduced-motion aware throughout.
- Launch languages: English · Spanish · French · German · Portuguese · Italian.
- Additional locales (Arabic, Chinese, Japanese, Korean, Hindi) are wired as resources but gated
  behind flags and excluded from the selector.
- Known gap: number/date formatting is currently device-locale bound.

## 9. Voice

AI Coach speaks in the locked persona voices and in the observation-only language locked across
every module (§64). It loads full context before responding — current HydroState, recent adaptive
response patterns, active Recovery Window, relevant Personal Response Library entries — never
starting from zero. **§42 language gate covers voice output.**
