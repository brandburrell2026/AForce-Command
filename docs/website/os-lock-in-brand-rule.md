# OS page brand spelling

The approved spelling is **LOCK-IN**: uppercase, with one ASCII hyphen.
Use it consistently in headings, body copy, accessible labels, dynamic demo states, screenshot lettering, product imagery, and film lettering. Punctuation may follow it (for example, `LOCK-IN.`). Asset filenames may use lowercase slugs.

When updating media, inspect the pixels rather than relying only on HTML or alt text. Preserve the source assets for rollback and use new asset filenames to avoid stale caches.

The edit prompt for each asset replaces only the brand phrase with `LOCK-IN`, preserving surrounding copy, layout, artwork, and transparency for the can cutouts. Each replacement was visually inspected and checked with OCR.
