# THE AFORCE CONTENT FLYWHEEL

The system's master loop. Every other workflow is a gear inside this one. The flywheel's promise: **the system continuously improves from actual AForce data** — every turn makes the next turn smarter.

```
        LISTEN
          ↓
IDENTIFY OPPORTUNITIES
          ↓
        CREATE
          ↓
        REVIEW
          ↓
        PRODUCE
          ↓
        PUBLISH
          ↓
        MEASURE
          ↓
   IDENTIFY WINNERS
          ↓
       REPURPOSE
          ↓
        ITERATE
          ↓
UPDATE BRAND + PERFORMANCE LEARNING
          ↓
     CREATE AGAIN
```

## The stations

1. **LISTEN** — Agent 17 (comments, questions, customer language), Agent 14 (trends), Agent 15 (data), leadership (`training/` drops). Inputs are real or absent — never imagined.
2. **IDENTIFY OPPORTUNITIES** — CCO + Strategist turn signals into the week's priorities (`/run-week` steps 1–4). Ideas that don't fit now go to the idea bank — the system never loses a useful idea.
3. **CREATE** — concepts → scorecard → hooks → scripts → copy (steps 5–8). Levels balanced 45/30/25.
4. **REVIEW** — Guardian (voice ≥8) → QA (12-point, claims flags) → leadership approval gate. Nothing skips the human gate.
5. **PRODUCE** — briefs + batch filming list; statuses PRODUCTION → READY TO EDIT → READY TO SCHEDULE (`dashboard/APPROVALS.md`).
6. **PUBLISH** — per calendar; post status updated; asset links recorded.
7. **MEASURE** — real metrics into `data/social_performance.csv` per the integration contract; partial data handled honestly (Agent 15).
8. **IDENTIFY WINNERS** — `workflows/winner-detection.md`: relative baselines, five winner categories.
9. **REPURPOSE** — winners get the full Agent-12 package within 72h; families tracked by content_id lineage.
10. **ITERATE** — `/double-down` variations; Agent 16 experiments settle open hypotheses.
11. **UPDATE LEARNING** — Agent 15 graduates PERFORMANCE INSIGHTS (`learning/content_insights.md`); Voice Training Engine converts leadership feedback into voice lessons; CCO proposes portfolio re-weighting as AI RECOMMENDATIONS.
12. **CREATE AGAIN** — next `/run-week` starts with everything the last turn learned.

## Flywheel health checks (monthly, CCO)

- Is anything entering LEARNING that isn't evidence-backed? (Category-tag audit.)
- Are winners actually getting repurposed within 72h?
- Is the approval gate a bottleneck (>48h median wait)? Report, don't bypass.
- Is any station starved (no community input, no trend input, no data)? Name the missing input to leadership — the flywheel slows honestly rather than spinning on fiction.
