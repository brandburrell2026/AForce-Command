# PERFORMANCE LEARNING LOOP

How raw metrics become durable knowledge — without ever laundering guesses into "insights."

## The pipeline

```
social_performance.csv  →  Agent 15 analysis  →  winner detection  →  pattern candidates
        →  Agent 16 experiments (when causality matters)  →  graduation review
        →  learning/content_insights.md (PERFORMANCE INSIGHT)  +  learning/performance_patterns.md
        →  consumed by: CCO portfolio, Strategist, Hook Writer, Calendar Manager, /double-down
```

## Graduation rules — what may enter `content_insights.md`

A statement graduates from HYPOTHESIS to **PERFORMANCE INSIGHT** only when all four hold:

1. **Real AForce data** — our accounts, our posts; platform-reported metrics in `social_performance.csv`. Benchmarks from articles/gurus are context, never evidence.
2. **Sufficient sample** — n≥5 comparable pieces per side of the comparison (n≥3 per arm for controlled experiments), stated explicitly.
3. **Meaningful margin** — the difference survives eyeballing the spread; near-ties are recorded as "no detected difference," which is itself an insight.
4. **Written with its evidence** — every insight carries: statement · evidence (metric, n, date range, platforms) · confidence (LOW/MEDIUM/HIGH) · date learned · review date.

Example of the required form (format only — do not treat as a real finding):

```
INSIGHT I-0xx [PERFORMANCE INSIGHT · MEDIUM confidence]
Statement: Question hooks outperform statement hooks on TikTok completion.
Evidence: 12 posts (6 question / 6 statement), Sep 1–28, completion 41% vs 29% median, TikTok only.
Learned: 2026-09-29 · Review: 2026-12-01 (revisit after 30 more posts)
```

## Decay and review

- Insights carry review dates; platforms drift. At review: re-confirm, downgrade to HYPOTHESIS, or retire to `performance_patterns.md` history.
- A single contradicting week never deletes an insight — it triggers a re-check with the larger sample.
- Confidence moves only on data, in both directions.

## What feeds back where

| Learning | Consumer |
|---|---|
| Hook-type patterns | Agent 04 rating calibration; `hook_library.csv` winner flags |
| Length/format patterns | Agent 05 defaults; Agent 16 next tests |
| Timing patterns | Agent 09 posting times (replacing the seeded hypotheses) |
| Talent patterns (founder vs. creator) | Agents 06/11/19 allocation |
| Pillar/level performance | CCO portfolio re-weighting proposals (AI RECOMMENDATION → leadership) |
| Flavor/product patterns | Product content emphasis; campaign planning |
| Voice/feedback lessons | Guardian via the voice-training engine (separate loop) |

## The prohibitions (repeated because they are the point)

Never fabricate metrics. Never generalize from one post. Never present platform folklore as our data. Never let an AI RECOMMENDATION or HYPOTHESIS sit untagged in a learning file. When in doubt: it's a hypothesis, and there's an experiment for that.
