# The AForce Content Department — 19 Agents

Orchestration: **01 CCO** runs the department. Creation: 03–14. Control: 02 (voice) and 18 (QA/claims) — every important piece passes both. Learning: 15–16. Community & creators: 17, 19.

| # | Agent | One line |
|---|---|---|
| 01 | Chief Content Officer | Orchestrates; balances Always-On/Campaign/Culture (45/30/25); never the copywriter |
| 02 | Brand Voice Guardian | Scores voice 1–10 vs. Brand Brain + feedback history; <8 rewritten |
| 03 | Content Strategist | Annual→weekly strategy; every piece tied to a measurable objective |
| 04 | Hook Writer | Openings only; 16 types; 20+ per major concept, all rated /40 |
| 05 | Script Writer | Spoken-not-written scripts in the production format |
| 06 | Founder Content | Brandon/Julius stories; canon + [SLOT]s; never fabricated biography |
| 07 | Education + Science | Three evidence lanes; flags every claim outside `CLAIMS.md` |
| 08 | Social Copywriter | Platform-native copy; never identical cross-posts |
| 09 | Calendar Manager | 7/30/90-day calendars; no-repetition system; production-aware |
| 10 | Creative Director | Briefs a filmmaker can shoot without questions; batch-filming aware |
| 11 | UGC Director | Native creator briefs; claims guardrails in creator language |
| 12 | Repurposing Engine | One piece → clips, hooks, carousel, posts, email, blog, podcast |
| 13 | Podcast Agent | Fueled by AForce pipeline: episodes → 5–10 claims-safe clips |
| 14 | Trend Scout | Scores trends (relevance/fit/speed/lifespan/risk); rejects most |
| 15 | Performance Analyst | Real data only; partial data honestly; graduates insights |
| 16 | Growth Experimenter | One-variable A/B tests; pre-committed decision rules |
| 17 | Community Agent | Comments → content; triage; community plan |
| 18 | Content QA + Compliance | Final 12-point gate; flags claims, never silently approves |
| 19 | Creator Manager | Creator database, seeding, deliverables, partnership performance |

All 19 are installed as invocable Claude Code subagents in the repo's `.claude/agents/` (e.g. `hook-writer`, `content-qa`). Each agent reads `../CLAUDE.md` and `../brand/AFORCE_BRAND_BRAIN.md` before working — no exceptions.
