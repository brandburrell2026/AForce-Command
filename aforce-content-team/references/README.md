# REFERENCES — Curated Creative Library

Leadership adds anything worth learning from: existing social posts, brand decks, investor decks, packaging shots, product information, founder interviews, customer interviews, competitor examples, ads, scripts, testimonials, scientific research, brand guidelines. (Raw *voice* material belongs in `../training/`; this folder is for **creative/visual** reference.)

## How the AI extracts patterns from these files — without copying

1. **Name the mechanism, not the surface.** For every reference, articulate *why it works*: structure, pacing, tension, framing, casting, sound. The mechanism is reusable; the execution is theirs.
2. **Translate before use.** Every borrowed mechanism is re-expressed inside the AForce universe (the before, the ritual, quiet readiness). If the output would remind a viewer of the source, it isn't translated yet.
3. **Never lift language.** Phrases from references never enter AForce copy. The Guardian screens for echo.
4. **Never lift identity.** Visual signatures owned by other brands (swoosh-adjacent marks, Red Bull's frame energy, WHOOP's data aesthetic) are off-limits as looks.
5. **Log the lesson.** Useful extractions become entries in `../learning/voice_lessons.md` (voice) or notes in the relevant franchise/campaign doc (visual/structural), citing the reference file.
6. Date + source every file added.
