# UGC-008 — The 90-Minute Block

**Creator type:** Entrepreneur / knowledge-work creator with a real deep-work practice (writer, engineer, designer, founder). Cast via Agent 19.
**Platform / length:** Reels + LinkedIn crosspost · 30–45s. **Franchise:** F11 The Demand (DEEP WORK). **Flavor:** Berry.

**THE ONE THING:** Focus is a performance arena too. The 90-minute block gets prepared for like a session: environment, inputs, one clear objective — then the door closes.

**TALKING POINTS:**
- Their block ritual: phone exile, single task chosen, water set BEFORE starting (no kitchen trips mid-block)
- What the block is for this day — real work, shown honestly
- The 60-minute wall and how they ride through it (their words)
- What changed when they started treating focus like training

**WHAT NOT TO SAY:** No cognitive-enhancement claims ("helps me focus" as personal routine is fine; "improves focus/concentration" as product effect is NOT); no productivity-guru numbers. FTC disclosure required.

**HOOK OPTIONS:**
1. "I prepare for 90 minutes of work like other people prepare for a workout."
2. "Everything my focus needs gets decided before 8:00. Nothing after."
3. "The block starts when the phone leaves the room."

**SCRIPT BEATS:** desk reset (clear, deliberate) → phone walked to another room (the signature beat) → water + stick set down at the desk corner → timer start → work montage (real screen, blurred where needed) → the 60-min stretch/sip beat → timer ends, one line on what got done.

**B-ROLL:** notebook single-task line · door closing · timer app · window light shift.
**PRODUCT INTEGRATION:** The set-it-before beat — preparation logic embodied; one glance, no lingering.
**CTA:** "What's your block ritual? Steal-worthy answers get featured."
**FORMAT SPECS:** 9:16 (+ 1:1 crop for LinkedIn); quiet ambient; no lo-fi-beats cliché unless it's genuinely theirs.
