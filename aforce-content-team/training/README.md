# TRAINING — Real Source Material In, Learned Voice Out

This tree is where AForce leadership continuously drops **real** source material so the system learns the AForce voice from evidence instead of assumption. The Brand Brain defines the brand; this folder teaches its sound.

**The engine:** `../workflows/voice-training-engine.md` analyzes what lands here — sentence length, vocabulary, rhythm, tone, energy, confidence, emotional intensity, storytelling patterns, opening styles, CTA styles, product/founder/educational language, premium vs. generic phrasing, messaging patterns, brand beliefs — and writes **rules, not memorized sentences**, into `../learning/voice_lessons.md` (each with evidence, confidence, supporting-example count, and date).

## The folders

| Folder | Contents |
|---|---|
| `approved/` | Content leadership shipped as written — strongest positive signal |
| `edited/` | AI draft + leadership final, paired — the richest lessons |
| `rejected/` | Killed drafts + reasons — anti-patterns |
| `competitors/` | Category content to learn structure from, never language |
| `customer-language/` | Real comments, reviews, DMs (anonymized) — audience diction |
| `founder/` | Brandon & Julius in their own words |
| `packaging/` | On-pack copy, dated by revision |
| `website/` | Canonical site copy (seeded from the live site) |
| `decks/` | Brand / investor / retail decks (sensitive numbers stay internal) |
| `product/` | Specs and formulation info — *candidate* facts until confirmed in `brand/` |
| `scientific/` | Substantiation for claims, with lanes and citations |

## Rules

1. **Real material only.** Nothing in this tree is synthetic except clearly-labeled contrast examples in `brand/VOICE_TRAINING.md`.
2. Date and source every file. Undated evidence is weak evidence.
3. One example never makes a permanent rule (unless leadership says "make this a rule").
4. Sensitive content (deck financials, contacts, anything personal) is learned from, never leaked into public content.
5. Drop files in any format — .md preferred, but screenshots/transcripts work; the engine transcribes what it can read.

**To trigger learning:** ask Claude to "run the voice training engine on training/" (or on a specific folder) after adding material.
